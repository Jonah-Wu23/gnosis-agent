# GNOSIS 下一步科研计划：业务反馈如何转化为可迁移经验

2026-10-13 · 组会讨论稿 · 新增实验预算 200 元

**研究问题：当自进化系统已经获得业务反馈时，反馈的组织方式是否决定哪些失败被写入经验，以及这些经验能否改善新任务？**

采用“历史谱系重建＋同源编辑干预”的研究设计。论文目标是解释业务反馈在经验形成过程中的损失，并测量定向干预的迁移收益。工具效率作为过程指标，业务要求完成作为终点。

## 一、核心理论假设

### 1. 本体论：究竟研究什么

| 编号 | 明示前提 | 直接约束 |
|---|---|---|
| H1 | 业务成功由任务授权下的对象状态和必要行动构成 | 工具正常返回与任务完成分别计量；需要保持状态的对象也属于任务目标 |
| H2 | 经验是一项改变后续决策的干预 | 版本哈希变化、条目增长均不直接记作能力增长 |
| H3 | 同一业务要求可以用不同句式表达 | “负极性”按禁止动作或保持状态的语义标注；不按否定词数量分类 |
| H4 | 经验形成包含证据送达、问题选择、经验写入和后续采用四个环节 | 每个环节使用各自的观察记录；不得由最终失败倒推某个中间环节缺失 |

### 2. 认识论：凭什么知道

| 编号 | 明示前提 | 直接约束 |
|---|---|---|
| H5 | 原始请求忠实记录模型实际收到的证据 | 以实际请求判定送达；登记 prompt 和组件装载只作索引 |
| H6 | 业务评价能区分真实完成与评分捷径 | 原严格评分保留，同时依据任务资料核对写入结果；争议要求单列 |
| H7 | 同题、同环境、同祖先下的受控编辑具有可比性 | 新实验统一模型与工具协议，并在同一时段交错运行各组 |
| H8 | 新任务与开发任务之间存在可复用关系，同时保留条件变化 | 按任务要求选择迁移题，禁止按方法运行结果挑题 |
| H9 | 实际费用足以完成预定比较，且停止过程不依赖效果方向 | 预算按完整比较块分配；记录全部失败与费用 |

**核心机制假设 H10：相同业务证据以“要求—对象—动作后果”组织后，比原生轨迹与断言列表更容易形成可迁移经验。** 评价覆盖排除要求与必要行动，取值正确性另行计量。H10的成立取决于业务完成的净改善。

## 二、关键逻辑链条

### 1. 已经成立的事实

ecai_p2 同样的 18 题、每组两次执行：fixed 有 651 次工具失败，GNOSIS 有 112 次；严格成功均为 20/36。global 有 165 次工具失败，严格成功 25/36。该批数据中，降低工具失败与提高业务成功没有保持一致排序。

现有修复器已经接收 `assertions` 与部分得分。历史 global 编辑依据行存在和行数断言修改经验；GNOSIS 编辑依据 `airtable_action_not_exists` 形成禁止更新的要求。**“系统只有工具报错这一种感知通道”与历史记录冲突，终止该主张。**

原始轨迹还显示，Xero在收到金额更正后仍写入旧金额；另一次执行实际抵用1,500、邮件报告2,000，却通过严格评分。前者暴露行动采用失效，后者暴露评价遗漏。研究分别处理这两个环节。

内部证据：[反馈入口](../engine/run_research.py)、[global 历史编辑](../experiments/research.source_20261007/global/workspace.json)、[GNOSIS 历史编辑](../experiments/research.source_20261007/gnosis/workspace.json)、[原始案例指针](../experiments/evolve_mine/mechanisms/trace_evidence.json)。

### 2. 从事实到待检验主张

1. 工具指标与业务终点排序不一致，经验发布应以业务要求完成为依据，工具指标用于衡量执行效率。
2. 业务反馈已经进入编辑器，研究对象转为反馈在后续环节的利用程度。
3. 部分经验已经包含排除规则，研究必须测量这些规则是否保留适用条件，以及在什么对象上被采用。
4. 若业务要求在原始输入中存在，却在编辑理由或经验中丢失，才能定位到经验形成环节。
5. 若经验保留了要求，而执行仍违反，问题定位到运行时采用；单改学习反馈的解释力随之下降。
6. 只有同源干预改善新任务的业务完成，才能把反馈组织的变化连接到迁移收益。

这条链对应三个明确主张：**C1，过程指标存在替代终点失效；C2，反馈组织影响经验形成；C3，经验形成的改善产生迁移收益。** C1 有历史依据，C2、C3 是新实验的研究对象。C2 失败后结束反馈组织主张；C3 失败后结束迁移收益主张。

### 3. Claude 六项建议的裁决

| 建议 | 裁决及理由 |
|---|---|
| A：替代终点失效 | 保留为问题入口。“失败次数≤8”登记为探索阈值；“18次降到3次没有收益”缺乏对应编辑的配对结果，终止该预测，改为测量新编辑的工具改善与业务收益 |
| B：痛觉驱动留下盲区 | “缺少断言感知”终止。改为检验业务反馈经过哪些环节后损失，以及反馈组织能否改变这种损失 |
| C：排除约束与双信号 | 保留排除要求作为分组；四字段经验已有 BASM 直接近邻。HR 延期备注存在评分粒度争议，退出“明确违规”的核心证据 |
| D：失败是超集漂移 | 终止多数严格超集主张。101 个同题同版本组产生 287 对成败执行，失败端点为严格超集的仅 21 对，同时有新增与遗漏的有 246 对；采用任务组等权时，严格超集平均占比为 5.74% |
| E：上下文强于版本编辑 | 保留携带前次轨迹的控制。它回答同题再次执行的价值；跨题迁移须另外评价。发现调用与实际动作先统一单位，同化比值暂不作为主指标 |
| F：发现过程偏差 | 模式条数只描述分析者产出；网络重叠只描述证据集合关系。它们均退出机制强弱排序 |

本次离线复算：377 个代际对中，父子平均失败次数都≤8的214对，失败减少量与部分得分变化的 Spearman 相关为 −0.075；跨越8次的104对为0.363；两端都>8的59对为0.278。共享祖先和重复任务造成依赖，这三个数作为描述。阈值是否能预测新编辑收益，必须在新编辑上锁定阈值后评价。[复算结果](../experiments/evolve_mine/mechanisms/next_plan_evidence.json)

## 三、假设敏感性测试

| 撤除或改变的假设 | 哪个结论崩坏 | 什么结论保留 | 对应压力测试 |
|---|---|---|---|
| H1：协议结果等同业务成功 | C1 的指标分离失去定义 | 工具调用效率的事实 | 在任务要求层核对工具正常返回后的对象结果 |
| H3：句式极性代表行动极性 | “负极性经验饥饿”分类崩坏 | 对象适用条件的研究问题 | 同义肯定、否定表达归入同一要求；不按词频计量 |
| H5：证据实际未送达 | “收到后未采用”解释崩坏 | 输入构造故障 | 对关键编辑逐项定位实际请求中的要求与反馈 |
| H6：原断言奖励了错误结果 | 严格成功增益作为业务增益的结论崩坏 | 原评价器上的分数差 | 分别报告原评分与业务状态；删除争议要求后重新估计方向 |
| H7：差异来自模型更新或环境变化 | C2、C3 的干预归因崩坏 | 历史相关 | 同批祖先重跑，各处理交错；模型或环境变化则整块失去比较资格 |
| H8：方法只记住本题对象和金额 | C3 迁移主张崩坏 | 同题修复能力 | 在全新对象、相反适用条件的真实任务上评价 |
| H10：更好组织没有改变经验内容 | C2 被否定 | C1 与运行时采用问题 | 比较要求进入经验的比例及适用条件完整性 |
| 方法收益来自额外信息或计算 | “组织方式本身有效”崩坏 | 增加资源后的整体方案收益 | 两种反馈携带相同事实；匹配编辑调用次数与内容预算 |
| 方法只减少行动、同时遗漏应做事项 | C3 的净收益崩坏 | 排除动作减少的局部事实 | 禁止动作减少量与必要动作完成率同时评价 |
| H9：均价显著上升 | 200元完成预定样本的计划失效 | 已完成块的实测结果 | 按下述盈亏点核算剩余完整块；不因显著性决定停止 |

撤掉H1或H6，C1失效；撤掉信息匹配或H7，C2失效；撤掉H8，C3失效。必要行动下降抵消排除收益时，方法判定失败。

## 四、边界条件与证伪机制

### 1. 研究范围

研究对象限定为冻结模型权重、通过外部经验更新的工具型 Agent，任务具有可检查的业务要求。以 AutomationBench 官方任务和原评分为实验环境，统一 DeepSeek 官方 `deepseek-flash`、high 思考、温度1、50步及现有权限。工具协议修复对所有组相同。

历史留出30题已参与全量分析，全部转为历史描述用途。新实验选24道未参与历史执行、深读或方法选择的官方任务；按六个开发来源各关联四道迁移题。若任务库不足以提供这种隔离，跨题独立评价的设计条件不成立，停止该实验。

### 2. 零费用的进入条件

重建GNOSIS 43次编辑与global 22次编辑。逐条标注实际可见反馈、编辑理由和新增经验，再关联后续执行。触发依据取自编辑前的实际输入与理由；缺失理由登记缺失，同一次编辑涉及多个问题时保留混合分类。

对196次有动作、零工具失败的业务失败，按“任务×失败要求”合并重复案例，逐项检查要求语义；另纳入原本成功的反例。排除要求的发生率以相关要求的暴露机会为分母。若原始反馈与经验已经完整保留关键要求，且主要分叉发生在执行采用，**终止学习反馈组织实验，将研究定位到执行采用。**

### 3. 新增实验：同源编辑的二因素比较

六个来源块使用六道真实开发任务，每块从同一冻结祖先出发。每块生成四个候选，各允许一次编辑和一次来源复测；来源失败也进入记录，禁止只挑成熟候选评价。

| 组别 | 反馈形式 | 经验表示 |
|---|---|---|
| F0R0 | 原生轨迹＋完整断言反馈 | 普通文字经验 |
| F1R0 | 相同事实按要求、对象与动作后果组织 | 普通文字经验 |
| F0R1 | 原生轨迹＋完整断言反馈 | BASM 启发的适用条件与规避要求 |
| F1R1 | 相同事实按要求、对象与动作后果组织 | 同一套边界经验表示 |

F1 的整理不得加入新答案或新来源，整理成本单独记账；F0、F1各自保留完整事实与相同编辑预算。R1 是已有表示范式的项目适配，语义由模型判定，程序只校验格式和权限。

每个候选在对应四道迁移题上各运行三次，共 **6×4×4×3＝288次**。加入同批冻结祖先72次，以及携带对应祖先轨迹的再次执行72次。总计432次评价；再次执行臂的首次费用使用祖先运行共同计入每条策略成本。

跨题主要比较是F1R0与F0R0：直接回答反馈组织是否改变迁移。F0R1与F0R0测量已有边界表示的作用；二因素交互回答组织反馈与边界表示是否互相依赖。携带轨迹臂单独评价祖先的同题重试：每次祖先首跑对应一次携带轨迹重试；新上下文重试使用该题祖先三次运行的固定循环配对（1→2、2→3、3→1）。两种策略均按两次执行计费，重复利用的配对在题内聚合，禁止择优。跨题主检验只使用各候选的新上下文首跑。

无合法候选时登记编辑失败，部署保留祖先，并将编辑失败率计入方法结果。

### 4. 主指标与判定

主要终点为任务级业务要求全部完成率，原严格成功率并列展示。要求分为必要行动、禁止行动和取值/对象正确性；每条评价必须关联任务资料及真实动作结果，标签在看组别结果前冻结。

主要效应为六个来源块的F1R0−F0R0差异，四道迁移题与三次运行先在块内平均。采用来源块配对随机化推断，同时报告逐块结果。预先规定10个百分点为实用增益：区间同时覆盖零与该阈值时，判定实验精度不足；整个区间低于该阈值时，判定未达到实用目标。

| 结果 | 裁决 |
|---|---|
| F1提高要求进入经验的比例，并提高新任务净完成 | 支持反馈组织机制；按实测区间报告效应 |
| F1改变经验内容，新任务收益为零或下降 | 终止迁移收益主张 |
| 只有R1有效，F1无增量 | 采用已有边界经验范式，终止新反馈方法贡献 |
| 只有F1R1有效 | 结论限定为两因素联合干预；反馈组织单独有效的主张终止 |
| 工具失败减少，业务终点未改善 | 报告过程收益与业务收益的分离 |
| 禁止动作减少，必要行动下降抵消收益 | 方法判定失败 |
| 同题携带轨迹以更低总费用取得相同或更好结果 | 同题场景优先采用轨迹复用；经验方法须靠跨题收益获得价值 |

## 五、范式对比与决策

| 范式 | 判断 |
|---|---|
| 用工具失败下降代表能力进化 | 要求级业务终点评价优于它，因为P2已经出现过程改善与终点排名不一致 |
| 痛觉、免疫、表观遗传比喻 | 可定位的反馈利用链优于它，因为后者能逐环节被反例推翻，且直接对应受控干预 |
| 只比较固定Agent与完整新方法 | 二因素比较优于它，因为可区分反馈组织的增量和已有边界表示的增量 |
| 增加适用条件、禁止动作字段作为创新 | BASM 已覆盖这一核心。项目应采用其边界思想作为强基线，方法创新必须来自反馈形成过程的新增证据 |
| 单次执行相关代替干预效果 | 同源编辑比较优于它，因为工具报错次数同时受任务难度和执行策略影响 |
| 完整重跑多条长期进化谱系 | 200元条件下，同源编辑干预优于它：保留因果问题的核心变化，避免把资金耗在重复探索；结论范围限定为局部编辑的形成与迁移 |

采用替代终点研究的两层结构：分别测量执行指标与业务结果的关系，以及编辑对两者产生的效果。377个历史代际对按任务和共享祖先聚合，新的干预按六个来源块推断。[Prentice](https://pubmed.ncbi.nlm.nih.gov/2727467/)；[Buyse等](https://pubmed.ncbi.nlm.nih.gov/12933525/)

BASM 已将适用条件和规避规则写入技能，并检查候选动作；本次阅读全文的方法部分及实验比较，明确将其列为直接近邻。GAUGE研究评价分数与真实任务完成的偏离；SilentProbe研究接口约束与静默失败。三者使“有静默失败”“多加边界字段”退出原创主张。[BASM](https://arxiv.org/html/2608.22339v1)；[GAUGE](https://arxiv.org/abs/2609.12191)；[SilentProbe](https://arxiv.org/html/2609.00035v1)

预算成立的关键假设是实际均价处于可容纳范围。固定编辑与整理支出为15元时，462次执行的均价上限为 **0.400元**。撤掉该费用假设，200元完成六块的目标失效。携带轨迹的输入费用计入实耗；每块包含四个候选及全部比较，按完整块交错执行，剩余预算不足以完成下一块时停止。完成六块才进入预定主检验。

按历史费用，推进200元的同源编辑实验优于重跑长期谱系。论文以反馈利用链的证据和受控干预结果为主干。若离线重建显示主要断裂发生在执行采用，直接转向该环节，终止反馈组织实验。

## 六、潜在逻辑陷阱与反例

| 审稿攻击 | 正面处理 |
