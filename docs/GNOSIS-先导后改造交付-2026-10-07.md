## 本轮修复

### 两个会毁掉整轮实验的缺陷

| 缺陷                                                      | 后果                                                         | 修复                                                         |
| --------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `call_location` 在未匹配路由的 URL 上崩溃                 | 原装 404 JSON 被 Python 异常替换，模型观测改写成非环境产物   | 定位函数对任意输入返回结果；接入层自身异常记 `harness_defects` 后抛 `HostError`，与环境失败分离 |
| 发布门死锁：validate 只收独立选择题，成熟条件只登记开发题 | 每轮验证被拒，发布版本永不推进，两个实验组冻结空组件组，主对照退化为基线 | 成熟条件只看工作版本，验证题目独立配对                       |

### 其余修复

- 观测账本补齐 verifiers 前置拒绝的调用并解析真实位置；
- 控制器统一收敛控制类异常（含模型反复给出不合协议操作）；
- 额度接口未配置时按账本调度并记录 `ledger_only`；
- 选择集成功不再登记成熟条件；
- 等美元组零成本与封顶退出、不撑爆评估池、为复测预留份额；
- 盈亏平衡改为实测累计摊销曲线加等美元核对；
- 复用准确性分母限定为“按范围复用、全局重跑”的题；
- 评估记录补回 `active_extensions` / `first_effect_boundaries` / `harness_defects`；
- 断点二次恢复不重复计费；
- worker 返回值转换失败归为候选故障；
- 组件发起调用统一经过调用前位置并触发其他组件干预；
- 操作函数跨任务隔离与权限拒绝反馈；
- 核心读数写进准入证明。

## 实验编排与预算

**执行顺序**：

固定 Agent 基线（30 题）→ 官方 ACE → 全局验证组 → 完整 GNOSIS → 四组最终留出（各 30 题）→ 等美元重复执行／修订组 → 汇总。

中途检查在任一臂学习支出过 50% 时触发，对照版本取首次达到成熟条件的版本。

| 项           | 取值                                                         |
| ------------ | ------------------------------------------------------------ |
| 任务划分     | 30 开发 / 6 独立选择 / 30 最终留出 / 6 中途检查，种子 100，identity `5dcb22fa…` |
| 分组学习额度 | `fixed 2.0` / `ace 3.0` / `global 4.5` / `gnosis 4.5`，合计 14 |
| 用途分配     | 学习 14 / 选择验证 8 / 留出评估与重测 14 / 余量 4            |
| 单次执行上限 | `$0.15`，所有组一致                                          |
| 等美元组     | 额度按评估池剩余减复测预留推导，单题上限与其他组相同，差别只体现在尝试次数 |
| 余量用途     | 服务失败重试、单题费用波动，两类之外拒绝                     |
| 发布门       | 确定性改进门加零回退约束，事先固定的配对统计完整写入 `paired_sage` |
| 汇总产出     | 每臂通过率、费用明细（学习/选择/检查点/留出/复测）、摊销成本、等美元对等度、累计摊销交叉点、各臂终止原因分布、发布状态与冻结组件数 |
