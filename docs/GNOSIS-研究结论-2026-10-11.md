# GNOSIS 研究结论：知识提供时机与验证边界

2026-10-11 · 依据 `experiments/timing_v4/`（240 条正式执行，全部保留资格）与 `experiments/timing_v4_recovery/`（恢复版本续跑：223 条盲审补齐、SKILLAA 三来源原生审计）· 统一统计输出 `experiments/timing_v4_recovery/analysis.json` 与 `skillaa/analysis.json`

## 一、五项条件逐项裁决

| 条件 | 裁决 | 证据 |
|---|---|---|
| 重要且原创的现象 | FAIL | 同内容时机变化未改变结果。主要检验：L 相对 D 的成功率差 × 来源类别交互 = -0.042，p=1.0（70 种置换），95% CI [-0.250, 0.125]。8 个来源中 5 个 L-D = 0，其余在 ±1/6 内摆动。修复效用本身微弱：6/8 来源中移除修复（N）与全局提前（G）成功率相同。"知识推迟到关键决策之后导致失效"的现象未出现 |
| 可重复机制 | FAIL | 无可重复的时机效应。过程证据（231 份有效盲审，9 条原生失败保留）显示 56 条轨迹存在约束损伤、88 条含恢复动作，但损伤与恢复不随 G/L/D/C/N 处理变化。20 条注册明确截止点的记录中，预测器登记的 TaskBoundary 在真实轨迹中全部不存在（deadline_violated 不可计算），"正文未出现 → 关键动作已发生 → 约束受损"的机制链无法建立 |
| 有效边界 | FAIL | 规划依赖与执行细节两类的效应差异判别失败（交互 p=1.0）。L 相对 G 非劣效成立（差 +0.021，95% CI [-0.042, 0.083]，精度 0.062 达标）：局部提前在统计上不损失修复效用，这是真实的局部提前成立证据；C 相对 G 的区间精度不达标（CI 半宽 0.115 > 0.1），契约提前的成立条件无法确认 |
| 执行前预测 | FAIL | GNOSIS 侧：冻结预测器输出恒为宿主可见性依赖集合的超集，捕获率与宿主集合完全相同，未在相同调用量下提高捕获；宿主依赖集合对每个来源覆盖整个审计池（重测比例 100%），选择性验证相对全量验证的费用反而更高（8 个来源的部署节省均为负，-0.19 至 -0.36 元/来源）。SKILLAA 侧两个来源的预测器输出不合规（invalid_model_output），捕获率未定义 |
| 外部成立 | FAIL（证据缺失型） | SKILLAA 原生审计三来源：来源 1 门禁接受，1 个范围外回归但复测未重现（同期无编辑翻转 1/8）；来源 2 无回归、门禁拒绝；来源 3 原生提议无合法单次编辑。可重复且被预测到的范围外回归来源数 = 0（门槛 ≥2）。注：此 FAIL 属证据缺失——两个完成审计来源的预测器输出不合规、第三个来源无编辑，不构成对覆盖缺口机制的经验否证 |

**主会裁决：FAIL。** 五项未同时满足，不进入论文写作。

## 二、统计结果全量记录

### H1：时机敏感性

- 主要检验（来源类别 × L/D 效应交互）：-0.042，p=1.0，70 种置换，CI [-0.250, 0.125]，不显著。
- 次要检验族（Holm 调整）：G-L = -0.021（p=1.0）；C-L = -0.063（p=0.5）；L-N = -0.021（p=1.0），均不显著。
- 逐来源 L-D：sales.negative_selection 0.0；operations.fire_suppression_testing 0.0；marketing.link_building 0.0；finance.refund_processing -0.333；support.hiver_team_performance -0.167；finance.xero_bank_reconcile +0.167；marketing.win_loss_analysis -0.167；hr.candidate_research_dossier 0.0。
- 过程指标：deadline_certainty 分布 absent 200 / clear 20 / uncertain 20；clear 记录的注册截止边界在真实轨迹中定位失败率 20/20；约束损伤 56/231；含恢复动作 88/231；恢复动作均值 0.78。

### H2：提前可见与局部验证

- L 相对 G：+0.021，CI [-0.042, 0.083]，精度达标，**非劣效成立**。
- C 相对 G：-0.042，CI [-0.146, 0.083]，精度不达标，非劣效不可判定。
- 局部验证经济性失败：宿主可见性依赖集合 = 全部审计池（8/8 来源重测比例 100%），路由加预测费用使选择性验证比全量更贵；这是任务池结构的直接后果，与预测器质量无关。

### H3：执行前预测的覆盖价值

- GNOSIS 侧：预测集合捕获率与宿主集合逐项相同，零增量；等调用量比较不成立（预测集合调用量更高）。
- SKILLAA 侧：`skillaa/analysis.json` — repeated_predictable_sources = 0，economic_sources = 0，external_threshold_met = false。来源 1 范围外回归 1 个、复测未重现；BigGate 与 LocalGate 接受数 1/2（已审计来源）。

## 三、停止规则触发与研究路线处置

- 时机对照无稳定差异：按研究计划 §9 终止 H1，"延迟导致修复失效"的主张终止（此为基于 240 条完整数据的统计否证）。
- H3 外部门槛未达（证据缺失型 FAIL）：两个审计来源的预测器输出不合规、第三个来源无原生编辑，机制既未被证实也未被经验否证；按停止规则终止外部缺口主张，保留真实负结果与可复用的 SKILLAA 原生审计接线。
- 原 GNOSIS 效果路线维持诊断结果；产品执行转入 PRD 的 L2 档。
- 本研究路线（知识提供时机与验证边界）的正式实验到此结束，不再新增。下一步转入 GNOSIS 历史轨迹离线二次分析（自进化闭环中的演化停滞、无效修改、能力退化与跨任务迁移）。

## 四、真实保留的资产

- **正向结果**：局部提前（L）相对全局提前（G）非劣效成立且区间精度达标——正文更新在固定路由下可以局部暴露，这是唯一成立的机制性结论；证据链完整（240 条、八来源、两次重复、统一分析）。
- **方法学资产**：评分重放器（暴露两处方法缺陷：末轮终止语义、环境生成值）；输入审计、会话审计、盲审恢复流水线；SKILLAA 原生门禁外部审计接线（官方 LocalGate/BigGate 完整保留）。
- **完整负结果档案**：时机效应为零、预测器零增量、选择性验证无节省、外部复现失败——排除"知识提供时机"作为主导机制。
