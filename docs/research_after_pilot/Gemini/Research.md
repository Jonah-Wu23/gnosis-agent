# 大语言模型智能体持续自进化实验失效机理诊断与前沿治理方案研究报告

## 实验结果不良的具体表现与系统性失效诊断

在基于复杂业务流程评测基准 AutomationBench v1.0.6 开展的大语言模型智能体持续自进化先导实验中，系统的核心设计目标是通过提议带作用域的知识单元、在使用时注入并基于局部影响面执行两段式回归门禁，以此实现低验证成本下的能力正向累积。然而，先导实验的最终评测数据与账本审计表明，系统未能建立持续自我改进的良性闭环，实验表现极度不佳。这种不良结果并非单一维度的随机性能波动，而是贯穿了“经验提炼—局部注入—行为遵循—门禁准入”整条流水线的系统性失效。

### 准入与采纳指标的全面归零

实验设计规划了最多六轮自进化迭代循环，受限于严格的预算熔断控制，系统在执行三轮准入检查后，可用余额降至 0.3378 美元，低于继续开展第四轮测算所需的单轮费用下限 0.6467 美元，因而触发预算停止机制（`budget_stop`）正常终止。在实际完成的三轮准入循环中，系统接受候选单元数为零，取代历史单元数为零，撤回单元数为零。

这种前序准入的完全停滞直接导致下游阶段末统计门禁发生严重饥饿。阶段末评估本应调用基于成对单侧二项检验的 SAGE 统计门禁（显著性水平设定为 $\alpha=0.05$、退化惩罚系数 $\lambda=1$、确认退化率上限 $\tau=0$）。但由于候选准入阶段未能筛选出任何合格单元，阶段末检验的输入配对样本量为零，胜负统计均为零，$p$ 值退化为缺失状态，最终裁决直接标记为不适用（`not_applicable`）。系统在先导阶段未能将任何一条提议经验沉淀进持久化知识库。

### 来源任务翻转条件的彻底落空

在两段式门禁机制中，候选单元进入知识库的首要必要条件是“使对应的来源任务由失败翻转为成功”。实验记录表明，三轮实验的所有候选单元无一例外均触发了 `source_task_not_flipped` 拒绝原因。第一轮候选单元针对发票归档任务，介入后 partial credit 依然停留在零分；第二轮候选单元针对预付费用摊销任务，介入后同样未能取得任何得分突破；第三轮候选单元针对项目盈利核算任务，介入后 partial credit 虽然由基线水平提升至 5/6，但由于未能满足终态严格断言，二元严格通过判定依然为失败。

尽管第一轮候选单元在八对独立测试任务中展现出微弱的跨任务泛化迹象（取得 2 胜 1 负 5 平，且初次失败的任务在二次确认复测中消除了退化），但在来源任务单点二元翻转这一硬性指标未达成的约束下，整个单元依然被绝对否决。

### 作用域设计彻底坍缩为全局经验

科研计划的核心理论创新在于“按改动规模计费的局部回归门禁”，其底层假设是大语言模型智能体的关键环境知识可以精准锚定在具体的服务或端点上（如 `google_sheets:values.append`），从而在使用时按需注入，并利用轻量级依赖图仅对触达该端点的任务执行局部重测。

先导实验的数据表明，提议模型完全丧失了细粒度端点知识的抽象能力。在完成的三轮提议中，模型产出的候选单元作用域全部退化为全局作用域 `GLOBAL`。由于标称为全局知识，系统无法从依赖关系中排除任何未调用该接口的任务，导致理论影响面瞬间膨胀至全量任务集。这使得“验证费用随单次改动的影响面增长、不随历史累积增长”的核心理论优势在先导阶段即失去了成立前提。

### 行为一致性断层与策略错误归因导致的负迁移

通过对底层执行日志中 29 次知识激活事件与 231 次组件调用追踪的人工语义审查，实验揭示了模型执行侧更为严峻的内部断裂。这集中体现为两种截然相反却同样致命的失效模式：

一种失效模式是知识激活后的行为完全忽略。第一轮单元明确要求智能体“终止漫无目的的端点探索，立即执行写入登记与邮件通知”，但在真实工具调用流中，智能体激活该知识后直接跳过了写入调用，导致原装登记与邮件断言全部落空，行为一致性判定为零。第二轮中的 T 组件在 HR 晋升通告任务中触发了提示事件，但智能体紧随其后的动作却是创建临时探测文件并继续在 Google Drive 中漫游读取，完全忽视了提示给出的业务目标，紧随行为同样不一致。

另一种失效模式则是错误知识被忠实执行所导致的负迁移。第三轮单元总结了一条错误的业务策略，要求智能体“在财务报告中包含所有符合范围的项目，并对负利润项目同时打上 At Risk 与 Low Margin 标记”。语义追踪证实，智能体以极高忠实度执行了该单元，在发送的汇总邮件中严格包含了 Delta 项目并添加了双重标记。然而，评测基准的原装任务断言明确要求**排除** Delta 项目。智能体越是忠实地遵循反思提议的规则，任务就越是稳定地失败，直接锁死了来源任务向严格通过翻转的可能性。

## 实验不良结果的深层致因机理剖析

### 弱监督与黑盒环境诱发的反思幻觉与因果归因谬误

提议模型在演化循环中的输入仅包含智能体的多轮交互轨迹、环境返回的错误信息以及最终的标量奖励 partial credit，评测基准底层的测试断言代码与黄金状态标准被严格屏蔽。在缺乏确定性梯度与断言细节的弱反馈黑盒设定下，大语言模型进行事后自省时极易陷入反思幻觉与归因谬误。

在长程多步骤复合 SaaS 交互任务中，智能体往往执行了数十次 API 调用，涉及跨系统的数据流转。标量得分下降或任务失败可能由多种不可见的微观因素引起，例如特定字段格式轻微不符、隐含时间戳校验失败或前置过滤条件缺失。由于无法感知真正的底层断言，提议模型仅能凭借轨迹末端的表面现象进行虚构的事后合理化解释。第三轮实验中，提议模型误将“未包含 Delta 项目”视作信息遗漏，从而生成了包含 Delta 的强制策略，而断言逻辑恰恰要求剔除该项目。当反思生成的经验本身在语义层面与任务正确目标相悖时，进化机制不仅无法纠偏，反而系统性地将错误固化为劣质经验，使智能体在后续执行中陷入不可逆的负迁移泥潭。

### 纯文本自然语言经验的因果非忠实性与长程注意力稀释

实验假设曾设想在使用时动态注入知识能够确保模型的高遵循度。然而，实验证据表明，纯文本自然语言形式的指导对模型决策的约束力极其微弱。

当模型在执行复杂业务流时，其上下文窗口中充斥着庞大的系统指令、长程交互历史、API 文档以及环境观测结果。在此类长上下文场景下，模型对中间动态插入的提示词存在严重的注意力稀释和长程指令遵循衰减。纯文字的劝诫性提示属于弱约束，其语义表征在解码过程中无法与模型在预训练阶段固化的强大工具探索先验和生成惯性相抗衡。因此，智能体即便在注意力计算中读取了该知识，在动作生成阶段依然会自发滑向低效的探测文件创建和端点扫描，导致行为一致率全面崩溃。

### 两段式门禁中源任务单次二元翻转的统计脆弱性

两段式门禁将“来源任务单次严格由败转胜”设立为不可逾越的绝对前置准入门槛。这一机制在数学逻辑上忽略了大语言模型决策固有的随机性以及环境执行的噪声干扰。

在历史测试中，同配置重复运行的代码序列差异率已高达 0.883，单题结果在基线自身重复运行间频繁翻转。AutomationBench 同样具有深层状态转移与复杂的 API 拓扑。在如此高方差的环境中，要求候选单元在且仅在一次重新运行中实现二元严格通过指标的绝对翻转，其统计检定功效极低，假阴性率极高。一个在本质上有益、能够规范接口参数或纠正跨任务通用调用缺陷的优秀单元，极有可能仅仅因为一次网络抖动、动作采样随机偏离或步数超限，而在来源题单次验证中偶发失败，进而导致整个单元被一票否决。这种刚性门禁设计直接阻断了有益经验的积累，使系统过早陷入自适应停滞。

### 提议器归纳偏置匮乏导致的作用域表征退化

先导实验复用了来自经典智能体架构的反思与整理提示词框架。这类框架原本是针对全局操作手册（Playbook）维护而设计的，其提示词引导模型对成功与失败进行宏观的方法论总结。

这种提示工程范式缺乏针对具体微观接口或参数模式的强类型归纳偏置。当 DeepSeek V4.1 Flash 面对整条数十步的失败轨迹进行归纳时，宏观总结提示词不可避免地促使模型提炼出高层级的业务概括。由于缺乏显式的模式槽位强制要求模型指明具体的 API 模式、参数键名或端点签名，模型倾向于选择认知代价最低的表征形式，直接将作用域字段标注为 `GLOBAL`。这导致底层设计的按改动规模计费与依赖追踪逻辑直接失去结构化语义输入，全系统退化为传统的全量低效扫描架构。

### 持续自进化有效性危机与状态化环境评估重构

在智能体自进化领域，近期一系列基准研究对“自进化能够稳步提升智能体能力”这一普遍假设提出了根本性挑战。

Continual Learning Bench（CL-Bench）构建了首个涵盖复杂企业级状态变迁、实体关联约束和多轮工作流的持续学习评测环境。其实验表明，现有的外置记忆架构与自适应框架在长程状态交互中表现极不稳定，性能分布呈现出围绕均值的散乱震荡，而非持续向上的学习曲线；在许多真实场景下，复杂的记忆演化系统甚至全面落后于纯粹的无状态朴素上下文学习（Naive ICL）。其根本原因在于状态化环境具有严格的外键依赖与实体持久性，任何一次包含微小瑕疵的经验沉淀，都会随着时间推移产生误差级联，导致后续多轮任务全盘崩溃。

Rethinking Harness Evolution 从计算与信息理论层面对“智能体外壳演化”进行了深入反思。该研究指出，许多声称 Harness 进化取得大幅涨分的工作存在方法论缺陷：进化搜索过程消耗了数千次推理步与丰富的任务反馈，实际上是一种变相的测试期搜索。当将 Harness 进化与相同推理计算预算下的朴素测试期缩放（Test-Time Scaling，如并行采样 Parallel Sampling）对齐比较时，Harness 进化无法展现出统计优势。更关键的是，该研究发现，在缺乏单元测试确切断言反馈的弱监督设置下，Harness 进化的性能往往直接跌破未演化的原始基线（Pass@1 从 68.2 降至 67.4）。进化模型学到的往往不是可迁移的设计模式，而是对训练集任务路径、特异性参数和已知 Bug 的机械背诵，在留出测试集上的迁移增益趋近于零（平均仅 +0.6 分）。

Bad Genius 提出的 CHASE 框架进一步揭露了自动 Harness 进化的“捷径学习”风险。研究表明，进化算法极易利用固定基准协议中的表面统计漏洞来“刷高”得分，一旦对评测协议施加合法的反事实变换，所演化出来的策略增益便会发生毁灭性瓦解。EvoAgentBench 与 SkillEvolBench 同样报告了大量由于提炼经验不当引发的负迁移现象，强调若无法实现精准的程序级抽象，注入的外置经验不仅无法助益推理，反而会成为阻碍模型原始能力的噪声干扰源。

### 弱反馈下提升反思精度与信噪比的归因机制

针对弱监督黑盒环境下的归因谬误，学术界的主流解决方案是引入结构化分解与对比分类机制。

GRASP 框架提供了一种极具针对性的设计范式。面对失败轨迹，GRASP 严禁提议模型直接开展发散性的自由文本反思，而是引入了一套机制特异性失败分类器。该分类器由专门的分类提示词驱动，将失败轨迹与该批次中的成功轨迹进行跨轨迹对比，并强制从开放词表中指派具备操作指导意义的机制标签（例如必须具体到 `date_filter_omitted` 或 `unvalidated_id_reuse`，严禁使用宽泛的 `wrong_answer` 或 `execution_failed`）。只有当失败模式被明确锚定到不可混淆的具体机制后，系统才按故障簇调用技能提议器。这种对比与聚类机制极大地过滤掉了单道题目特有的偶然性干扰，确保提议器面对的是具有统计共性的因果事实，从根本上消除了由于主观臆断导致的虚假归因。

在 EvoAgentBench 中，研究人员采用了跨模型与跨轨迹比对提取器。当单一任务失败时，提取器不直接基于该失败轨迹做单点归因，而是对照多条成功与失败样本，寻找执行状态树上的“判别性验证步骤”与状态分叉点，从而使提炼出的反思知识具备扎实的反事实因果支撑。

### 经验表征形式重塑：从非忠实文本提示转向确定性接口中间件

针对纯文本经验在长程决策中缺乏约束力且极易被模型忽视的问题，近期发表在 ICML 2026 与 AI 领域的里程碑工作从经验表征的底层给出了理论解释与工程出路。

赵伟翔等人的研究系统性地揭示了智能体自进化的“因果非忠实性”。研究通过严格的因果干预实验证明了一个普遍存在的非对称现象：智能体对详细的原始轨迹经验具有高度的因果忠实性，而对模型自行提炼、总结出的浓缩文本经验表现出极弱且不一致的因果敏感度。在绝大多数情况下，即便将浓缩经验的内容完全替换为无关文字或破坏性语义，模型的成功率也几乎没有显著变化；更为严重的是，高度浓缩的经验在知识密集型长程任务中经常主动诱发“目标偏离”、“固化错误先验”与“早熟推理”三大破坏性行为模式。这从计算认知机理上直接解释了先导实验中单元激活后行为一致性普遍为零的内在原因。

林敏华等人的工作则进一步解耦了进化系统中的两个独立维度：Harness 更新能力（提出有效更新）与 Harness 获益能力（智能体执行侧真正从中受益）。其实验指出，模型更新 Harness 的能力与基础能力关系较为平缓，但获益能力在长程交互中会迅速遭遇天花板，尤其在复杂工作流的深层执行阶段，智能体对 Harness 指令的遵循度衰减速度高出强模型数倍。该文得出的明确结论是：单纯在提示词层面叠加文字指南是低效的，必须将能力预算从提议端转移到执行与接口约束端。

基于上述发现，前沿架构正在全面由“自然语言提示演化”向“强类型可执行构件演化”转移。GRASP 规定技能单元严禁写作自由散文，必须为包含 YAML 元数据头的严格结构化 Markdown 文档，显式定义触发条件、行为规则以及用于校验副作用的后置核验步骤。AEROS 架构与 ECM Contracts 系列工作则更为彻底，将智能体进化的载体形式由文本直接降阶为具身能力模块与接口中间件。经验不再作为提示词让模型去阅读理解，而是作为代码编写的客户端接口包装规则直接挂载在底层 SDK 上。例如针对分页遗漏，包装规则直接在网络层实现自动静默翻页；针对数据写入，包装规则强制实施写后回读；针对参数漂移，包装规则执行严格的模式校验与重试。通过将进化成果直接下沉为确定性代码构件，彻底绕过了大语言模型概率解码的不可靠性与注意力衰减，实现了确定性的行为采纳。

### 轻量化回归验证与统计门禁架构

在回归测试与门禁验证方面，完全放开门禁会导致退化经验污染知识库，而过于严苛的单题二元门禁又会导致统计检定功效不足并误杀潜在有益单元。前人研究在软件工程与统计决策理论中给出了双重借鉴：

SAGE 确立了防范优化器诅咒的严密数学基础。SAGE 通过引入非对称效用差值 $\Delta_\lambda = w - \lambda \ell$、成对单侧二项检验 $p_\lambda(w, \ell) < \alpha$ 以及退化率硬性上限约束 $\rho = \ell / n_S \le \tau$，成功在 20 个大模型评测设定中将智能体自演化的退化率压制到接近零。SAGE 的理论指出，当评估样本量较小（如先导实验中的 8 对）时，在统计学上若出现任何负样本，检验必然弃权。因此，SAGE 的正确用法是作为宏观阶段末的批量检验器，而不应降维作为微观单次提议的前置过滤漏斗。

为解决微观验证成本与噪声问题，自动化软件测试选择技术提供了经典的依赖隔离机制。Ekstazi 以及后续的 STARTS 与 FineEkstazi 通过在动态执行中构建轻量级的文件依赖校验和，实现了“改动仅重跑受影响测试用例”的安全裁剪，在工业界持续集成中削减了 $30\% \sim 65\%$ 的执行时间，且未引入任何安全违规。

在机器学习系统测试中，针对模块化能力更新提出的原子质量探针与混合选择器架构进一步推进了这一思路。该研究证明，直接使用端到端复合任务来评估单次能力更新不仅测试成本高昂，而且系统级粗粒度评估会严重夸大“全量重测”的必要性，并被复合任务中的无关链路噪声所掩盖。每一个能力模块首先由一个极低成本的原子探针 $q(c)$ 进行单点行为保真度评估；混合选择器在原子探针边际明显（显著优于或劣于阈值）时直接做出准入或拒绝裁决，仅当原子探针处于狭窄的不确定边际区间时，才唤醒开销巨大的复合任务重测流水线。这种分层过滤思路有效化解了微观验证的高成本与高方差难题。

此外，在统计序列检验领域，序贯概率比检验（SPRT）被广泛引入大模型评测与对抗自对弈中。SPRT 允许在样本到达时动态更新对数似然比，一旦达到统计置信边界即提前终止采样，从而在保证第一类与第二类错误率受控的前提下，以最小的平均采样样本量完成模型升级决策，避免了固定轮次评估中因预算过早耗尽而导致的死锁。

## 持续自进化系统架构演进路线与治理建议

针对先导实验暴露出的根本性缺陷，并结合前沿文献的成熟方案，后续系统研究应当由浅入深，从提议引导、表征形式、门禁统计学设计以及科学基准校准四个层面实施系统性重构。

### 提议机制重构：机制特异性对比分类与强模式作用域约束

当前基于单条失败轨迹的自由文本发散式自省提示词必须彻底废除，提议阶段应当解耦为两步流水线。在触发提议之前，系统应引入机制特异性失败分类器，将失败任务的多轮交互调用链与同领域（或该任务历史基线中的成功片段）进行对比，通过少样本演示强制提议模型输出细粒度的失败机制类别，并明确圈定发生异常的具体服务与 API 端点名称。

在分类完成后，提议器模板必须实施基于模式校验的结构化约束。强行剥夺模型将作用域泛化为 `GLOBAL` 的自由度：除非提议的是全局通用的元程序规则（如强制写后回读），否则作用域字段必须通过枚举校验，强制绑定到轨迹中实际触发错误的 API 路径（例如 `google_sheets:values.append`）。内容字段必须包含三元组结构：触发前置条件、确定性动作规范以及用于确认状态迁移的显式断言检查，消除因主观臆测导致的虚假因果归因。

### 经验表征降阶：全面启动 A5 降级路线转向客户端接口包装器

鉴于大语言模型对浓缩自然语言经验普遍存在因果非忠实性与长程注意力衰减，系统应果断启动预研方案中的 A5 降级出口，推动经验形态从“给模型阅读的提示词”向“直接控制通信的中间件”转移。

在具体工程实现上，系统应在网络客户端实现插件式的 API 拦截器层。提议器不再输出自然语言短文，而是输出受限沙箱内的结构化包装规则（例如以 JSON 或 Python 规范形式声明的参数修正字典、自动重试协议、列表自动追加与校验回读探针）。当智能体向目标端点发起调用时，拦截器在底层透明地对 Payload 实施校验与参数规范化，并在必要时自动执行预检调用与写后核验，直接把正确的行为注入到网络通信层而非模型提示词中。这种方式从物理层面将行为一致性提高至百分之百，彻底切断模型因长上下文遗忘或惯性推理导致的策略漂移。

### 门禁流水线解耦：微观原子探针准入与宏观统计检验分层

针对当前两段式门禁中“源任务单次严格翻转”的刚性脆弱性，应借鉴原子探针理论重构准入流水线，将微观准入与宏观阶段末门禁彻底解耦。候选单元产生后，第一道防线不再是直接重跑高成本且充满全链路噪声的复合任务，而是构建轻量级的端点级原子探针测试。例如针对 API 参数包装规则，直接在模拟环境中单步回放触发该错误的具体请求与上下文片段；若原子探针确认修复且未引发局部异常，即赋予初级准入资格。

对于涉及复合任务的端到端验证，系统应当废除“单次运行严格通过”的二元硬指标，转而采用容忍噪声的软化指标。在阶段一准入中，允许使用多次重复采样的期望得分增益 $\mathbb{E}[\Delta \text{partial\_credit}] > 0$ 或采用 Pass@3 替代单次 Pass@1，以此抵消环境网络抖动与动作采样的随机方差。阶段末门禁则继续保持严谨的 SAGE 配对统计检验，但通过在准入阶段累积多批次合格的局部单元，并在受影响任务并集上做批量验证，保证进入 SAGE 检验时样本量达到能突破显著性门槛的有效规模，彻底消除阶段末门禁因无输入而退化为不适用的设计死锁。

### 预算对齐验证与科学停止准则实施

根据前沿评估方法论的警告，任何声称智能体自进化有效的系统，必须在同等计算与反馈预算下证明其优于简单的测试期缩放。

在后续展开正式实验时，必须严格将系统的全流程总花费（包括提议生成、原子探针、局部成对验证与阶段末检验）与基线配合测试期缩放（如两次独立采样结合自评估选择，或带验证器的并行采样）进行端到端的预算对齐评测。若在修正后的架构下，作用域化自进化的留出集泛化增益无法在相同 API 成本下显著击败测试期缩放基准，则应遵循科研计划既定的停止准则，转而产出客观的负结果刻画与系统诊断性学术成果，真实反映冻结基座模型在企业级状态化环境下的自进化能力边界。
